# CodeAlpha Python Programming Internship

This repository contains all four tasks I completed for the **CodeAlpha Python Programming Internship**. Each task is in its own folder with its own detailed README.

## Tasks

| # | Task | Folder | Key Concepts |
|---|------|--------|--------------|
| 1 | Hangman Game | [Task1_Hangman](./Task1_Hangman) | `random`, loops, if-else, strings, lists |
| 2 | Stock Portfolio Tracker | [Task2_StockPortfolio](./Task2_StockPortfolio) | dictionaries, input/output, arithmetic, file handling |
| 3 | Task Automation (Email Extractor) | [Task3_EmailExtractor](./Task3_EmailExtractor) | `re`, file handling, `sys.argv` |
| 4 | Basic Chatbot | [Task4_Chatbot](./Task4_Chatbot) | if-elif, functions, loops, input/output |

## Requirements
- Python 3.8 or higher
- No external libraries needed (only the standard library)

## How to Run
Open a terminal inside the task folder and run the script:

```bash
cd Task1_Hangman && python hangman.py
cd Task2_StockPortfolio && python stock_tracker.py
cd Task3_EmailExtractor && python email_extractor.py
cd Task4_Chatbot && python chatbot.py
```

## What I Learned

- Validating user input and handling errors
- Working with dictionaries, sets, and files (`.txt` and `.csv`)
- Using regular expressions to automate a repetitive task
- Writing rule-based logic for a simple chatbot
